# Design references

Screenshots of financial products we take inspiration from for KEEL's dashboard,
accounts, ledger, and account-breakdown views. KEEL's own aesthetic stays "financial
calm, not fintech neon" (Law 8): Tailwind stone neutrals + deep emerald, red = negative
money only, dense but breathable.

- `copilot/`  — Copilot Money (primary reference: calm, dense, category/insight visuals)
- `monarch/`  — Monarch Money (net worth, accounts grouping, cash flow)
- `quicken/`  — Quicken / Simplifi (classic register/ledger density, reports)
- `other/`    — Mercury, Lunch Money, Linear, etc.

Captured from public marketing/product pages. Not for redistribution — internal design
reference only.
