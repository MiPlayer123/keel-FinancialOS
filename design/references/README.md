# Design references

Screenshots of financial products we take inspiration from for KEEL's dashboard,
accounts, ledger, and account-breakdown views. KEEL's own aesthetic stays "financial
calm, not fintech neon" (Law 8): Tailwind stone neutrals + deep emerald, red = negative
money only, dense but breathable.

See `INDEX.md` for the per-app catalog and the WANTED list of manual (logged-in)
captures, and `DESIGN-NOTES.md` for the distilled patterns.

- `copilot/`          — Copilot Money (primary reference; includes 7 macOS desktop shots + web)
- `monarch/`          — Monarch Money (iPhone set + iPad set + web)
- `quicken-simplifi/` — Quicken Simplifi (iPhone + iPad + web)
- `quicken-classic/`  — Quicken Classic (iPhone companion + iPad + web)
- `ynab/`             — YNAB (iPhone + iPad + web; envelope budgeting canon)
- `rocket-money/`     — Rocket Money (subscriptions/cancellation patterns)

File naming: `<platform>-NN-description.png` (curated official set) and
`appstore-<app>-<platform>-NN-<WxH>.jpg` (native-resolution App Store rips;
`appstore-manifest.json` records the exact source URLs). Manual logged-in captures
go in the matching folder as `own-NN-description.png`; community/review-site finds
as `community-NN-description.jpg`.

Captured from public marketing/product pages and developer-published App Store
listings. Not for redistribution — internal design reference only. Reference for
FLOWS and patterns, not pixels (INDEX.md usage rule).
