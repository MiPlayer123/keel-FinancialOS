# KEEL current UI snapshots

Dated, logged-in captures of KEEL's own web app, for gap analysis against
`design/references/` and as a before/after record of design passes.

- Snapshots are point-in-time; trust the date in the folder name, not the pixels.
- Captured with Playwright at 1440px (deviceScaleFactor 2) full-page, plus
  390px mobile shots of key surfaces (Law 8 floor).
- Captures contain real account data, so dated folders are gitignored and stay
  local only (privacy pass 2026-08-18). Never commit or redistribute them.

Refresh at milestones: re-run the capture into a new dated local folder.
