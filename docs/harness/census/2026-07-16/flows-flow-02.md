## Flow steps
**Lunch Money CSV import (flow-09 → flow-10):**
1. Do → open "Upload your files" dialog. See → account destination pre-filled to "Lenny's Checking (Depository)," empty dropzone, optional "ADDITIONAL SETTINGS."
2. Do → attach/drop a CSV. See → dropzone replaced by a listed file "My 2024 Transactions.csv (13kb)" with a remove (✕) control; primary CTA updates to read "PROCESS 210 ROWS" (row count computed from the file).
3. Do → click "PROCESS 210 ROWS" (or, alternately, "VIEW RAW DATA" for an unmapped look at the file — an offered detour, not confirmed where it leads). See → "Match CSV columns" screen: each CSV column header becomes a dropdown pre-guessed against Lunch Money's fields (Date, Category, Payee, Amount all auto-detected, per the populated dropdown values), with a live preview of the actual row data underneath.
4. Do → open a column dropdown (shown: "Date"). See → a field list with "Do not import" plus the full target-field set, "Required" badges on mandatory fields (Date, Payee, Amount) and none on optional ones (Category), with checkmarks against the currently-selected mapping.
- No confirmation/success screen or undo affordance is captured beyond this point in the evidence.

**Simplifi onboarding (flow-13 → flow-14 → flow-15):**
1. Do → land on "Welcome to Simplifi" after signup. See → reassurance copy, single "Get started" CTA, no back control (this is step 1).
2. Do → click "Get started." See → "Add accounts" empty state: illustration, explanatory copy about business/personal separation, single "Add Account" CTA, and now a back-arrow appears (can return to Welcome).
3. Do → click "Add Account." See → "Add account" → Intuit consent screen: explains the Intuit relationship, offers three collapsed disclosures for more detail, requires implicit consent via "Continue," and now both a back-arrow and a "✕" close are present (can abandon add-account entirely, not just step back).

## Business rules implied
- A hard row ceiling on file import exists and is disclosed up front: "The total number of rows must be less than 10,000." (flow-09).
- Only CSV and PDF are accepted upload formats for this Lunch Money dialog (flow-09), vs. YNAB's importer supporting "OFX and QFX" as recommended and "QIF and CSV" as merely supported (flow-11) — implying a format preference hierarchy exists (some formats are worse for the importer than others).
- Column mapping distinguishes required from optional target fields: Date, Payee, and Amount are marked "Required"; Category is mappable but not required (flow-10) — a transaction can apparently be imported without a category.
- "Do not import" is a first-class mapping option per column (flow-10), implying import is column-selective, not all-or-nothing per file.
- YNAB treats manually-entered and file-imported transactions as reconcilable against each other automatically: "Transactions entered by you will match automatically. Direct Import duplicates are skipped." (flow-11) — stating an explicit dedupe/matching rule at the point of import, and that dedupe applies specifically to "Direct Import" (a separate concept from this manual File Import path).
- YNAB account balance is modeled as two additive components reconciled into one total: Cleared Balance + Uncleared Balance = (implied running) total (flow-11), and the account itself carries a persistent reconciliation-status flag ("Not Yet Reconciled") shown as chrome next to the account name rather than as a per-transaction attribute.
- Simplifi transaction edits can be selectively excluded from downstream calculations at two independent granularities — "Spending Plan" and "Reports" — each with its own checkbox and its own named blast radius ("Affects Spending Plan calculations." / "Affects Reports, Watchlists, and Upcoming Summary.") (flow-12): exclusion is not a single blanket toggle, it's scoped per consumer of the transaction.
- Simplifi's "Billable" flag appears gated on "Clients & Projects" being set (rendered disabled/muted until then) (flow-12), implying billability is meaningless without a client/project context.
- Simplifi frames third-party data access explicitly as a consent transaction with named data broker: "Quicken Simplifi uses Intuit to connect" / "We need your consent to access your data." / "By continuing, you consent to let Intuit share your data with Simplifi..." (flow-15) — consent is per-provider-relationship, not a generic ToS click-through.
- Simplifi separates "Tags" and "Categories" as two independent, co-located taxonomies (flow-16): tags are flat chips with no visible hierarchy or type; categories are hierarchical (group → subgroup → leaf) and each row carries a "Type" (seen: "Expense") and a dedicated "Tax Form & Line Item" column — implying categories (not tags) are the tax-relevant classification axis.

## Standout details
- Lunch Money injects the live row count directly into the primary CTA label ("PROCESS 210 ROWS") rather than showing it as separate helper text — the button itself communicates scope before commit.
- Lunch Money's column-mapping step reuses the data-table's own column headers as the mapping controls (dropdown-as-header) instead of a separate two-column "source field → target field" mapping UI — collapses two mental models (preview + mapping) into one table.
- Lunch Money marks per-field requiredness with small gray "Required" badges inline inside the dropdown's option list, not just via asterisks on labels — visible only once the dropdown is opened, a progressive-disclosure choice.
- YNAB's File Import modal proactively addresses the user's top likely anxiety before they ask ("Worried about duplicates?") and states the resolution rule directly in the dialog copy, plus offers a persistent "Don't show again" dismissal so the teaching moment doesn't repeat.
- YNAB pairs a contextual teaching tooltip ("Import transactions from a bank file.") directly on the toolbar button the first time (or every time?) it's relevant, rather than relying solely on the modal's own copy.
- Simplifi's transaction-detail modal spells out the exact downstream effect of each exclusion checkbox in a one-line caption directly beneath it, rather than leaving "Exclude from Reports" to be self-explanatory — reduces the chance of a user under- or over-excluding a transaction.
- Simplifi's onboarding consent screen visualizes the Intuit relationship as a literal bidirectional-arrow diagram between two logo marks before any text is read — a wordless trust cue up top.
- Simplifi's "Add accounts" empty state uses a single decorative arrow graphic to physically point at the one available action, reinforcing there's exactly one thing to do here.
- The floating sparkle-icon button anchored bottom-right of the Settings page (flow-16) persists even on a dense administrative screen, suggesting the AI-assistant entry point is global chrome, not scoped to transaction-level surfaces only.
