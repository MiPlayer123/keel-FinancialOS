## Standout details
- **Bar-chart-as-table-row background** in the Cash Flow report (image 01): each row's colored background width is scaled to the row's percent-of-total, so the ranked list doubles as a horizontal bar chart without any separate chart widget — a compact way to show both exact figures and relative magnitude in one glance.
- **Sign-aware coloring**: a negative expense figure gets a green (not red) row treatment (image 01) — a small but meaningful deviation from "red = bad, green = good" that instead encodes "money returned to you = good" even inside an expenses list.
- **Two parallel card stacks for one feature**: Bills/Subscriptions (image 05) and Complete/Upcoming (image 08) both render as two overlapping, drop-shadowed cards fanned out diagonally — a distinctive marketing composition, but the underlying pattern (a running "$X remaining due" total plus a uniform icon/name/cadence/amount/timing row) is consistent and reusable across four different card variants.
- **Freshness as content, not metadata**: per-account "N hours ago" sync labels (image 07) are shown with the same visual weight as the balance itself, right under it — treating data recency as something the user should see at a glance per account, not buried in a settings/status page.
- **Goal hero imagery + inline status badge**: the goal detail screen (image 06) uses a full-bleed photo with overlaid name, ownership badge, status pill, date, and progress bar all directly on the image — maximizing information density without a separate header block.
- **AI sparkle icon reused across card headers** (image 08) rather than as a one-off button — suggesting a consistent "AI touched this" iconography convention applied wherever automated categorization/detection contributed to a list.
- **Dual "value" framing on Goals** (image 06): showing both "Total saved" and a separate "Available to spend" — implying goals distinguish money contributed from money still spendable, a subtlety a simpler goals feature might collapse into one number.
