# Archive: historical phase plans

Point-in-time planning and status documents from Stage 0 and Stage 1 (July 2026). They are kept for traceability because NOTES.md, code comments, and harness plan fragments cite them by filename (for example `PLAN-FEATURE-PARITY.md` or `C5C-BUILD-SPEC.md`), but they no longer describe the current system.

For current state, read in this order: `/CLAUDE.md`, `/INFRA.md`, `docs/BC-v2.1.md`, `docs/19-KEEL-CURRENT-STATUS.md`, and the running build journal `/NOTES.md`. Active design planning lives in `docs/harness/`.
